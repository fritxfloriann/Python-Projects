# CLI.PY

The `cli.py` is a terminal-based wrapper for the unit converter program that can be run from your terminal or command prompt. The `cli.py` program has a different interface from `unit_converter.py`, mainly due to its terminal-based interface. This README offers instructions, commands, and installation guides on how to use the `cli.py` program. 

*Both `cli.py` and `unit_converter.py` are different wrappers with different interfaces and instructions. Both still depend on the `converter.py` dependency.*

# INSTALLATION

To install `cli.py`, you need `cli.py` and `converter.py` installed. For the installation guide, follow the steps below.

Why download `converter.py`? This file is a dependency used by `cli.py` and `unit_converter.py`. It is required to be installed. While you can install both programs independently, it won't work because they need the `converter.py` dependency. `cli.py` and `unit_converter.py` are wrappers for the program.

You must have Python 3.10 and Python 3 installed on your system. You also need a terminal or a command prompt.

Install the repository by cloning it with Git or install it as a ZIP folder.

After installation, both `cli.py` and `unit_converter.py` require `converter.py` to be in the same folder. For your convenience, each wrapper comes bundled with `converter.py` in its folder. Reminder: the dependency is named differently for each wrapper.

Upon installation, run `cli.py` with Python 3 or Python, depending on your system.
