# Python-Projects

This repository contains all the projects, mini-projects, and programs I've coded in Python. Each has its own purpose and use, so read its README before using any program to get started.

Each program will have its own README for the user as a mandatory requirement for each file. The README would be in `.txt` format with a ".README" at the end to label the file as a README. 

## Where is the source material for these projects?

The source materials for these projects are located in my pinned repository, `Basics in Python`, which contains guides, comments, and step-by-step improvements of my journey. This repository is aimed at separating my projects from my experimental and journal repository for regular users who want to access my projects.

## Will there be projects with a different programming language?

Yes! In the future, I will also include projects with other programming languages like C++, C, CSS, and etc. But there is an asterisk. Projects with a different coding language much contain a percentage of usage using Python. This is to make sure the repository still has Python elements.
