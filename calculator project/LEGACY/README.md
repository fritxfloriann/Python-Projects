## LEGACY FOLDER

This folder contains the legacy version of `calculator_main.py`. This is the first version of `calculator_main.py` that offers all the basic operations and capabilities. There were implementations of error handling, additional mathematical operations, and calculations. It performs basic calculations and is limited to only two numbers at a time before the program stops.

It is outdated by today's standards. The legacy file is only to be used for testing, experimental, and basic purposes, as its capabilities are extremely limited. The error handling could cause the program to exit, which is an issue for basic use. I recommend using the newer calculator program, `calculator_main.py`, in this folder. It is much easier to use for basic calculations.

*This file is discontinued and will not be maintained, modified, or edited.*
